   수치는 근거 있는 것으로 보는 substring fallback을 코드 게이트에 추가하고 회귀
   테스트를 남겼다. 생성 프롬프트에도 원문에 없는 %, 배, 단위 표기 금지를 명시했다.

   함께 골드 Task에 `required_concept_groups`(생산량·산출량지수·노동투입량지수)를 달았다.

   규칙과 320자 제한을 프롬프트에 명시하고 `required_concept_groups`(프로그램 매매·5%·
   하루·40분·서킷브레이커)를 달았다.
5. **행동 시나리오를 핵심 요소로 오판** — `콜옵션`. 승인본은 행사/포기 시나리오를 뺐는데
