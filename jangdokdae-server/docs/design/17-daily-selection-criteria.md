# 하루 세 콘텐츠 선택 기준

> 상태: 초안 v1 (2026-07-28, 사용자 검토 대기)
>
> 근거 데이터: 2026-07-16~26 사용자 라벨 11일치(`evaluation/learning/tasks/selection_gold.jsonl`)와
> 현재 휴리스틱 베이스라인(top-3 overlap 18.2%).

이 문서는 두 가지 용도다.

1. **라벨링 기준** — 사람이 골드셋을 만들 때 일관되게 판단하기 위한 규칙.
2. **점수 모델의 사양** — 알고리즘이 근사해야 할 목표. 점수 모델은 이 문서를 코드로
   옮긴 것이어야 하고, 문서에 없는 신호를 임의로 추가하지 않는다.

## 1. 전제

- 대상 독자는 **관심사 없는 주식 초보자**다(게스트 시나리오). 로그인 사용자의 관심사
  반영은 이 기준 위에 얹는 별도 레이어다.
- 세 개는 각각 고르는 게 아니라 **하루치 조합**으로 고른다. "그날 이 셋만 읽으면
  균형 잡힌 하루"가 되는지가 최종 판단이다.
- 양질의 후보가 부족하면 적은 수만 낸다. 빈자리를 채우려고 기준을 낮추지 않는다.

## 2. 역할 정의

| 역할 | 정의 | 판단 질문 |
|---|---|---|
| 핵심 (focus) | 그날 가장 중요한 **구체적 사건** | "오늘 하나만 읽는다면?" |
| 맥락 (context) | 개별 사건 너머 **시장 전체가 움직인 이유·상태** | "오늘 시장은 왜 이랬나?" |
| 발견 (discovery) | 앞의 둘과 **다른 영역**에서 시야를 넓히는 배울거리 | "안 보던 세계 중 오늘 배울 것은?" |

역할 경계 규칙:

- 시장 전체급 대사건(급락·서킷브레이커 등)은 그날 1순위면 **핵심**에 둘 수 있다.
  역할 라벨보다 조합의 균형이 우선이다.
- 맥락은 지수·금리·환율·물가·수급처럼 **시장의 상태 변화**를 우선한다. 제도·규제
  발표는 시장 전체에 영향이 있어도 "상태"가 아니라 "사건"이므로 기본적으로 핵심/발견
  후보다.
- 발견은 "중요도 4위"가 아니다. 중요도가 낮아도 **다른 산업·자산군의 배울거리**면
  좋은 발견이다. 핵심·맥락과 섹터가 겹치면 발견 자격이 없다.

## 3. 공통 점수 축

각 후보는 역할 적합성과 별개로 아래 축으로 평가한다.

### 3.1 파급력 (impact)

- **보도량**: 클러스터에 묶인 기사 수. 여러 매체가 다뤘다는 것 자체가 신호다.
- **출처 다양성**: 서로 다른 언론사 수. 한 매체의 연쇄 보도와 구분한다.
- **출처 가중**: 메이저 언론이 다뤘는지에 가중치를 둔다. 언론사 등급표는 사용자
  편집 판단으로 확정한다(미확정 — 후속).
- 단, 라벨 데이터 기준 보도량은 **약한 양의 신호**다(사람 선택 중앙값 7 vs 풀 6).
  현재 중요도처럼 보도량을 과도하게 밀면 오히려 사람 기준과 어긋난다(알고리즘 선택
  중앙값 10). 파급력은 문턱(너무 작은 클러스터 제외)과 보조 가중으로 쓰고, 단독
  1순위 신호로 쓰지 않는다.

### 3.2 신선도 (novelty) — 최근 발행 3일과 비교

- 비교 대상은 풀 전체가 아니라 **최근 3일간 실제 발행한 항목(최대 9개)**이다.
  초안은 "어제 3개"였으나, 라벨 데이터에서 사람의 반복 회피 기억이 하루보다 길어
  (사이드카·급락류를 며칠간 회피) 재현 평가를 근거로 3일로 넓혔다(2026-07-28).
- 어제 발행분과 **같은 stable 클러스터**이거나 내용이 실질적으로 같으면(임베딩
  유사도 기준) 강한 감점. "단일종목 레버리지 규제", "사이드카 발동"이 며칠 연속
  등장하는 문제를 막는다.
- 예외: **새 전개가 있는 후속 보도는 허용**한다. 같은 주제라도 새로운 사실·결정·
  수치가 중심이면 신선한 것으로 본다. (라벨 데이터에서도 사용자는 10일 전환 동안
  8건의 주제 연속을 허용했다 — 전면 금지가 아니라 "무전개 반복 금지"다.)
- 판단 질문: "어제 그 기사를 읽은 사람이 오늘 이걸 읽고 새로 배우는 게 있나?"

### 3.3 초보자 학습 가치 (learnability)

- 이 사건을 통해 **시장의 작동 원리를 하나 배울 수 있는가** (예: 실적 발표가 왜
  주가를 움직이나, 유가와 항공주의 관계).
- 종목 시세 중계("○○ 10% 급등, 원인 미상")처럼 배울 구조가 없는 것은 감점.
- 특정 종목 추종 매매를 부추기는 구도는 제외한다(매수·매도 힌트 금지 원칙과 동일).

## 4. 조합 규칙

1. 세 개의 섹터가 가능하면 겹치지 않게 한다(발견은 필수, 핵심·맥락 간에는 권장).
2. 세 개가 모두 같은 거대 주제(예: 반도체)로 수렴하면 하나를 다른 영역으로 바꾼다.
3. 어제의 3개와 조합 수준에서도 달라야 한다 — 세 자리 중 두 자리 이상이 어제와
   같은 주제면 그날 선택은 실패로 본다.

## 5. 점수 모델 v1 매핑 (예정)

| 축 | 신호 | 데이터 |
|---|---|---|
| 파급력 | 클러스터 기사 수, distinct 언론사 수, (후속) 메이저 가중 | `news_cluster.size`, `news.news_source` |
| 신선도 | 최근 3일 발행분과 stable_id 일치 / 임베딩 유사도(0.82+ 하드 제외) | `news_cluster.stable_id`, `news.embedding` |
| 학습 가치·역할 적합 | LLM 편집 판정(`selection-judge-v1`) — 후보별 learn_value·역할 fit 점수 | `scripts/judge_learning_candidates.py` |
| 후보 범위 | 당일 실행분 우선(라벨 33/33이 당일 후보) | `news_cluster.run_date` |
| 조합 | 맥락 먼저 확보, 지수 시세형(시장 전체+PRICE)은 핵심에서 제외, 섹터 중복 제약 | `news_analysis.scope/frame/sector_ids` |

검증(2026-07-28 1차): 운영 휴리스틱 18.2% → 코드 신호만(v2) 18.2% → LLM 판정 결합(v3)
**33.3%** (`evaluation.learning.run_selection --model v3`, 11일 순차 시뮬레이션).
코드 신호만으로는 사람의 편집 판단(주주환원·실적 같은 학습 가치 선택)을 재현하지 못했고,
LLM 판정 축이 필수임이 확인됐다. 골드셋이 작으므로(11일, 단일 라벨러, 일관성 한계 인지)
추가 튜닝은 과적합 위험이 있어 1차는 여기서 멈춘다. 남은 불일치의 상당수는 "둘 다 타당한"
선택이라, 다음 단계는 정답 일치율 대신 **수용률 평가**(모델 선택을 사람이 허용/불허로
검토)와 라벨 추가 축적이다.

## 6. 수용률 평가 (2026-07-28)

v3의 11일치 선택 33건을 사용자가 "그날 나갔어도 괜찮았는가"로 검토했다
(`evaluation/learning/tasks/selection-acceptance-2026-07-28.json`).

- **수용률 84.8% (28/33 허용)** — 정확 일치율 33.3%와의 격차는 대부분
  "둘 다 타당한" 선택이었다.
- 불허 5건 중 4건이 **무전개 반복**(사이드카 ×2, 레버리지 규제, 유가) — 임베딩
  유사도만으로는 주제 단위의 반복 피로("매수 사이드카" vs "매도 사이드카")를 못
  잡는다. 사용자 판정 기준: *"지난 N일 동안 나온 내용인데 새로운 점이 있었는가?"*
  → 이 판정을 게이트 앞단에 넣는 것이 다음 보정(v4)이다.
- 1건은 **설명 깊이 부족**(실적 기사인데 이유·구조 설명이 없음) — 발견 역할은
  "왜"가 기술된 콘텐츠만 자격이 있다.

### 파생된 제품 아이디어 (사용자 제안, 기획 미확정)

무전개 반복이나 얕은 이슈를 버리는 대신, 메인 3개 아래에 **"한줄 정리" 섹션**으로
여러 개를 묶어 내보내는 방안. "하루 3개로 끝"이라는 핵심 규칙은 유지하면서, 그날
있었던 나머지 흐름을 부담 없이 훑게 한다. UI·API 변경이 필요하므로 별도 기획으로
다룬다.

## 7. 미확정 사항 (사용자 판단 필요)

1. **언론사 등급표** — 메이저/일반 구분과 가중치.
2. **"새 전개" LLM 판정(v4)의 구체 프롬프트·비용** — 최근 발행분과 겹치는 후보에만
   호출하는 조건부 판정.
3. **한줄 정리 섹션** 기획 여부와 UI 형태.
4. 기존 11일 라벨 중 이 기준과 어긋나는 날의 **재라벨 여부**.
